# Cali Tetris

Handheld-style falling blocks with a California sunset look and an original lo-fi hip-hop soundtrack, all synthesised in the browser (no audio files).

- `npm run dev` to play locally, `npm run build` for a static build in `dist/` (relative paths, so it works from a subfolder).
- `npm test` runs the engine tests.
- Rules follow the original handheld: 10x18 well, no hold or hard drop, no wall kicks, one-piece preview, 40/100/300/1200 scoring, level up every 10 lines.
- Controls: arrows or WASD to move, X or Up to rotate clockwise, Z to rotate back, Enter to start, P to pause, M for music. Touch buttons appear on phones.
